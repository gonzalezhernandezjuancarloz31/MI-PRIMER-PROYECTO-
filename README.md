# Portal Web de Cálculo Diferencial - ITCM (Instituto Tecnológico de Ciudad Madero)

> Plataforma educativa integral diseñada para los estudiantes del **Instituto Tecnológico de Ciudad Madero (ITCM)** para dominar el programa oficial de Cálculo Diferencial (Clave ACF-0901) del **TecNM** y acreditar la materia en primera oportunidad.

---

## 🚀 Características Principales

1. **Temario Oficial TecNM (5 Unidades Completas):**
   - **Unidad 1:** Números Reales y Desigualdades (Axiomas, Intervalos, Desigualdades Lineales, Cuadráticas y Valor Absoluto).
   - **Unidad 2:** Funciones (Dominio analítico, Rango, Composición y Funciones a Trozos).
   - **Unidad 3:** Límites y Continuidad (Indeterminaciones $0/0$, Factorización, Racionalización, Límites Trigonométricos).
   - **Unidad 4:** La Derivada (Interpretación geométrica, Regla de la Cadena, Derivación Implícita y Orden Superior).
   - **Unidad 5:** Aplicaciones de la Derivada (Criterios de 1ª y 2ª Derivada, Máximos, Mínimos y Optimización).

2. **Cuestionarios de Autoevaluación Interactivos:**
   - Evaluaciones instantáneas al final de cada unidad con retroalimentación y explicación detallada paso a paso.

3. **Calculadora 'Salva el Semestre' (Mínimo 70+ TecNM):**
   - Simulador inteligente que aplica el reglamento oficial de acreditación del TecNM.
   - Detecta si estás acreditado en 1ª oportunidad o si debes presentar Segunda Oportunidad (Evaluación Complementaria).
   - Calcula cuántos puntos requieres en las unidades faltantes.

4. **Simulador de Examen Departamental Contrarreloj:**
   - 10 reactivos aleatorios de las 5 unidades.
   - Temporizador de 20 minutos con cuenta regresiva.
   - Diagnóstico final de aciertos por unidad, veredicto TecNM y revisión completa con soluciones.

5. **Formulario Dinámico (Cheat-Sheet):**
   - Buscador en tiempo real de fórmulas de derivadas (algebraicas, trigonométricas, inversas, exponenciales, logarítmicas) e identidades trigonométricas.
   - Botón para copiar código LaTeX al portapapeles.

6. **Guía de Supervivencia ITCM:**
   - Errores clásicos donde los profesores descuentan puntos.
   - Libros recomendados (Stewart, Larson, Granville).
   - Canales de YouTube salvavidas (JulioProfe, Profe Alex, Matemáticas con Juan).

## 🛠️ Tecnologías Utilizadas

- **HTML5 Semántico**
- **Tailwind CSS** (vía CDN para máxima portabilidad)
- **KaTeX** (Renderizado matemático nítido de ecuaciones LaTeX)
- **Lucide Icons**
- **Canvas-Confetti** (Efecto visual al aprobar con 70+)
- **Vanilla JavaScript ES6+** (Sin frameworks pesados, carga instantánea)

## 💻 ¿Cómo abrir y usar el proyecto?

1. Simplemente haz doble clic en el archivo `index.html` en tu explorador de archivos para abrirlo en cualquier navegador (Chrome, Edge, Firefox, Safari).
2. O inicia un servidor local ligero:
   ```bash
   npx serve .
   ```
   o con Python:
   ```bash
   python -m http.server 8000
   ```

3. **Para publicarlo en la web gratis:**
   - Puedes subir esta carpeta a un repositorio de **GitHub** y activar **GitHub Pages**.
   - O arrastrar la carpeta a **Netlify Drop** o **Vercel** para tener un link público compartible por WhatsApp con tus compañeros de clase.
